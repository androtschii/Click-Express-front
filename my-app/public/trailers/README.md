# Trailer Images

Поместите изображения прицепов в эту папку с названиями:

## Required Images

1. **flatbed.png** - изображение платформы 53'
2. **stepdeck.png** - изображение степ-дека 48'
3. **conestoga.png** - изображение конестоги 53'
4. **lowboy.png** - изображение лоуборда / RGN

## Notes

- Размер: рекомендуется 600x400px или больше для оптимального качества
- Формат: PNG, JPG, или WebP
- Ориентация: горизонтальная (landscape)
- На снимке должны быть видны соответствующие прицепы из фото из приложения

Когда вы поместите изображения здесь, они автоматически появятся в разделе "Our Fleet" на странице FleetPage.
